## 📋 Overview

A visually stunning single-page landing page for **Sugar Rush Bakery**, an artisan bakery brand. Features a 3D interactive background, glassmorphism UI, and smooth animations.

### 🎯 Features

| Feature | Description |
|---------|-------------|
| 🌌 **3D Animated Background** | Three.js floating orbs with parallax effect |
| 🪟 **Glassmorphism UI** | Modern frosted-glass design |
| 🧲 **Magnetic Buttons** | Interactive hover effects |
| ✨ **Ripple Effects** | Click feedback animations |
| 📜 **Scroll Animations** | Intersection Observer fade-up effects |
| 📱 **Responsive Design** | Mobile-friendly layout |
| 📋 **Full Sections** | Hero, About, Menu, Gallery, Testimonials, Contact |

## 🛠️ Tech Stack

- **Three.js** — 3D graphics & parallax background
- **HTML5** — Semantic structure
- **CSS3** — Custom properties, keyframe animations, responsive design
- **Vanilla JS** — Interactivity & animations

## 🖼️ Sections

1. **Hero** — Gradient text with animated entrance
2. **About** — Stats showcase (50+ recipes, 12k customers, 8 awards)
3. **Menu** — Product cards (croissant, sourdough, cupcake, cookie, tart, cake)
4. **Gallery** — Visual showcase
5. **Testimonials** — Customer reviews
6. **Contact** — Inquiry form
